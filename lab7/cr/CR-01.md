# CR-01 — Mostrar «Pendiente de sincronización» con fecha y hora de captura

| Campo | Contenido |
|---|---|
| Fecha | 15/11/2026 |
| Solicitante | Producción / TI (propuesta de la matriz de ajustes de la Reunión 2; simulada para este laboratorio) |
| Origen | Matriz de ajustes del Avance 3, fila «Registro offline» |
| Línea base afectada | LB-1.0 (tag v1.0-iter1) |
| Tipo / prioridad | Cambio de requisito (RF02) / Should |
| Justificación | El operario y el encargado de almacén necesitan saber qué registros siguen sin sincronizar y desde cuándo para no perder ni duplicar lotes (RNF03, riesgo R4 del Lab. 6). |
| Impacto en alcance | RF02 se amplía con un criterio visible; no se agregan casos de uso ni requisitos nuevos. Afecta HU02 y HU03. |
| Impacto en tiempo | 3 h estimadas (capacidad: 88 h por sprint = 3.4%) |
| Impacto en calidad | Mejora la verificabilidad de RF02 con un escenario nuevo (PR-RF02-03, PR-RF02-04). |
| Riesgos | Bajo: la clase RegistroPendiente ya guarda fechaHoraCaptura y estadoSync; solo se expone su etiqueta. Riesgo de saturar la pantalla móvil (RNF04). |
| Mitigación | Mostrar solo etiqueta y hora en una línea (WF-02) y mantener botones grandes. |
| Decisión | **ACEPTAR** — Costo bajo, valor alto para la excepción real de conectividad y sin impacto en el alcance ni en el presupuesto. |
| Ruta de trazabilidad | RF02 → CU02 → HU02/HU03 → CL07, CL10 → SEQ-02 → PR-RF02-01…07 |
